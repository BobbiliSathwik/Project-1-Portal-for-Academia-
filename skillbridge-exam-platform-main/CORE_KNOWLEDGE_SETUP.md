# Core Knowledge Check

Upload `core-knowledge-10.txt` in the Examiner Portal and choose **Core Knowledge Questions** as the bank type. Then select it under **Core Knowledge Bank (optional)** when creating an exam.

The check triggers around the middle of an adaptive assessment, pauses the main timer for 60 seconds, asks 10 basic questions, and uses 8/10 as the pass threshold. Its score is stored separately and is not added to the main skill score.
